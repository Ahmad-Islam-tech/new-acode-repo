# Noor Library — Flutter Starter

This is an organized starter project for a learning-focused Islamic digital library app.

## Included in this starter
- Home screen with feature navigation
- Book library and sample book data
- Book details and a simple reader
- Hadith, Qur'an, bookmarks, and settings placeholder screens
- Reusable feature and book cards
- Centralized app theme and routes
- Explanatory comments throughout the important widgets and operations

## Run it
1. Open the project in a Flutter-enabled workspace.
2. Ensure the project root contains `pubspec.yaml`.
3. Run `flutter pub get`.
4. Run the app on a device/emulator.

## Important content note
Sample Islamic content is illustrative placeholder content. Before publishing, verify Qur'an text, hadith wording, references, and authenticity grades against reliable editions/scholarly sources. Do not treat sample text as a verified religious source.

## Learning approach
Start with `lib/main.dart`, then `lib/app/app.dart`, then the screens. Each screen is kept separate so the project can grow without repeatedly replacing one giant file.
